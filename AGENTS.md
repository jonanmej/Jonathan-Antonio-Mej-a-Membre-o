# Persisted AI Agent Rules & Conventions

## Document Generation Compliance (ISO 9001)
From this point forward, **ALL** documents generated by the application (including PDFs, CSVs, Excel files, printed reports, lists, etc.) MUST strictly comply with ISO 9001 document control standards (applicable to ISO 9001:2015 and ISO 9001:2026).

Whenever a feature involves generating a document or report, you MUST include:
1. **Document Identification Box/Header**:
   - `CÓDIGO`: (e.g., FOR-FSM-001, FOR-OPE-04, etc. - assign a logical alphanumeric code).
   - `VERSIÓN`: (e.g., 01, 02, etc.).
   - `FECHA`: The current dynamic date of generation.
2. **Standardized Footer on EVERY page**:
   - Pagination: "Página X de Y".
   - Printing metadata: "Impreso por: [User/System] - [Date/Time]".
   - **Mandatory Compliance Statement (centered, italicized)**: "Documento controlado aplicable a SGC bajo norma ISO 9001:2015 / ISO 9001:2026."

*Do not skip this requirement for any new export or print functionality requested by the user.*
